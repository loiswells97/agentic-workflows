
## Library docs

Before writing or changing code that uses a third-party library, framework or API (React, Vite, pytest, ruff, etc.), look up the current docs with context7 (resolve-library-id, then query-docs). Don't rely on memory for APIs, config keys or CLI flags. If context7 has nothing on it, say so before going ahead.
